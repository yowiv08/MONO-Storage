# MONO 功能说明

## 访问地址

| 功能 | 地址 |
| --- | --- |
| 文件获取与分享 | `/` |
| 管理后台 | `/<后台路径>` |
| 存储 API | `/api/buckets/workspace` |
| MCP | `/mcp` |
| AI 调用说明 | `/api/mcp/guide` |

## 文件管理

支持文件和文件夹上传、拖拽上传、大文件分片、目录导航、搜索、筛选、排序、预览、下载、分享及批量删除。

文件工具栏提供“批量操作”。列表和网格视图都可多选、全选已加载且符合筛选的文件、反选及清空选择，查看所选数量与总大小，并执行打包下载、复制完整路径及确认后的批量删除。

工作空间的“分享链接”集中显示有效分享及对应文件，支持查看存储桶、大小和有效期、复制或打开链接、打开文件及取消分享。

顶部文件数量与总大小随当前目录更新，包含该目录及全部子目录中的文件；返回“全部文件”后显示整个存储桶的统计。目录标记与系统对象不计入，搜索、筛选或列表分页不改变统计范围，切换目录、上传、覆盖、删除及手动刷新后更新。

## 文档查看

点击文件名或缩略图打开查看器。后台和公开分享页面都支持格式预览与原文切换。

| 格式 | 格式预览 | 原文 |
| --- | --- | --- |
| Markdown（MD、Markdown） | 标题、段落、列表、任务列表、表格、代码块及引用 | Markdown 文本 |
| PDF | 分页阅读、页码输入、缩放、适应宽度及旋转 | 当前页提取的文本 |
| Excel（XLSX、XLS、XLSB、XLSM）、ODS | 工作表切换、单元格表格、合并区域、常用数字和日期格式、分页 | 当前工作表的值和公式，按制表符分隔 |
| CSV、TSV | 表格及分页 | 原始分隔符文本 |
| Word（DOCX） | 正文标题、段落、列表、表格及嵌入图片 | 提取的文档文本 |
| HTML、JSON、普通文本 | 安全正文排版、JSON 格式化或文本显示 | 文件文本 |

PDF、Word 和 Excel 在线预览支持 32 MiB 以内的文件，文档压缩内容解压后最多 64 MiB。文本最多显示前 2 MiB；表格每页 100 行，预览最多 5000 行、200 列及 250000 个单元格，较大的文件会明确提示预览范围。原始文件始终可以下载。

Excel 按文件保存的数值显示，不执行公式或宏；复杂图表、完整样式和打印排版可下载查看。扫描 PDF 可能没有可提取文本，可以在格式预览中查看页面。加密 PDF 可输入文件密码在当前浏览器中解锁，密码不会保存。

文档内容在浏览器内解析，不上传到第三方预览服务。HTML 和 Markdown 不执行脚本，未嵌入文档的图片不自动加载。PDF、文档与表格的读取继续遵守原文件及分享权限。

## 设置与权限

侧栏底部的“设置”支持修改工作空间名称、后台路径和管理员密钥，以及创建、编辑、停用和撤销 API Token。

“登录限速”支持配置每个来源 IP 在任意连续窗口内的最大尝试次数。默认 10 次 / 60 秒，支持 1–100 次及 10–3600 秒，保存后立即生效。成功和失败均计数，超限显示等待倒计时。

首次安装无需安装密钥，初始化完成后不能再次触发安装。

Token 支持全部存储桶、单桶和精确单文件范围。权限可选择只读、只写、读写、ALL，或分别授权读取、写入、删除、创建目录、删除目录与分享。单文件 Token 仅允许访问对应文件。

## API 与 MCP

HTTP API 使用 Bearer Token，支持文件列表、信息、内容读写、Range、条件覆盖、文件统计、目录和分享管理。

### 文件内容追加

`POST /api/buckets/{bucket}/object/append?key=完整路径` 将请求正文原样追加到文件末尾，保留已有内容、文件类型和自定义元数据。需要 `write` 权限，单文件 Token 只能追加指定文件；不要求读取权限，也不会返回原文或原有自定义元数据。

请求正文是新增字节，必须提供其准确的 `Content-Length`。不自动添加换行；日志、Markdown 或 CSV 需要换行时应在正文里包含换行符。该操作不会解析或合并 JSON、PDF、Excel 等结构化文件。

默认要求文件存在；添加 `create=true` 可在不存在时创建，`Content-Type` 仅在创建时使用。成功返回 `key`、`size`、`etag`、`appendedBytes` 和 `created`，已有文件返回 200，新建文件返回 201。

“设置 → 文件追加”可配置追加后的完整文件上限，范围 1–5115 MiB，默认 90 MiB。保存后对新的 API 和 MCP 请求立即生效；降低上限不会删除或截断已有文件，超过新上限的文件不能继续追加。最大值受 Cloudflare 单次对象写入上限约束，单次 HTTP 请求还受部署平台的请求大小限制。`If-Match` 可限定文件版本；并发冲突返回 `409 APPEND_CONFLICT`，本次内容不会写入。追加不是幂等操作，网络超时后应先核对结果，不能盲目重试。缺少长度返回 411，超出上限返回 413。追加改变文件版本，已有分享链接随之失效。

MCP 提供 `mono_append_text` 和 `mono_append_base64`，每次新增最多 1 MiB，支持 `createIfMissing` 和 `ifMatch`。后台“API 访问”提供 cURL、JavaScript 和 Python 的追加示例。

MCP 使用 Streamable HTTP 和独立 API Token，按授权范围和权限提供文件工具。后台“API 访问”页提供连接地址、客户端配置示例、AI 调用说明复制和 Markdown 下载。

完整 API 调用指南和后台脚本需鉴权。匿名状态不提供产品版本、运行环境或后台配置，首次安装仅使用必要的初始化状态。

## 存储与界面

线上文件保存在 Cloudflare R2，存储桶为 `mono-storage`，API 别名为 `workspace`。本地运行使用持久化的本地 R2 状态。

支持白天与黑夜模式、图标主题切换、顶部菜单跳转，以及问号帮助弹窗。辅助文字保持可读字号。
